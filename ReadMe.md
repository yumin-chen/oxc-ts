# Starter Template

## Scripts

- `npm run build`: Bundles the project using `vp pack`
- `npm run dev`: Runs watcher build using `vp pack --watch`
- `npm run test`: Runs test suite using `vp test`
- `npm run check`: Performs code formatting/linting/type checks using `vp check --fix`
- `npm run fmt`: Formats codebase using `vp fmt`
- `npm run lint`: Fixes lint issues using `vp lint --fix`
- `npm run prepare`: Configures git hooks / Vite+ config using `vp config`
